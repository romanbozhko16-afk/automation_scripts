скролле, парящие карточки, бегущая строка услуг, автокарусель отзывов,
плавный аккордеон FAQ, параллакс фото в шапке.

Данные (услуги, цены, контакты, фото) — те же, что и в первой версии.

- Всё в одном файле `index.html` + фото `daryna.jpg`.
