## Проект 2: 2Easy Automation (сайт для бизнеса автоматизации)

**Кто клиент:** сам пользователь, его компания называется «2Easy Automation»
(без «Co.» — убрано по явной просьбе). Услуги: кастомная автоматизация

**Файлы:** `2easy-website/index.html` (всё в одном файле), `2easy-website/og-image.png`

**Референс:** пользователь просил ориентироваться на концепцию сайта

**Задача от клиента:** «премиальный дизайн, максимально живые анимации
везде — чтобы при наведении мышкой на любое окно тоже была анимация, уровень

## Общие технические заметки (для продолжения в любом инструменте)

- Оба сайта — статические одностраничники: чистый HTML/CSS/JS в одном
  файле, без сборки, без npm/фреймворков. Открываются прямо в браузере.
- Все анимации на чистом CSS + vanilla JS (IntersectionObserver для reveal
  on scroll, requestAnimationFrame для счётчиков, mousemove для tilt/magnetic/
  glow). Никаких внешних библиотек анимации не подключено.
- Шрифты подключаются через `<link>` на Google Fonts CDN (не встроены как
  файлы — при переносе в ChatGPT/другой редактор ссылки на Google Fonts
  нужно сохранить, иначе шрифты не подгрузятся).
- Оба сайта respect `prefers-reduced-motion` — при этой настройке ОС все
  анимации отключаются.
- Готовы к публикации на GitHub Pages / Netlify / Vercel без изменений.
