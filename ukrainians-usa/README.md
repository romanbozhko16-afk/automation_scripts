# Ukrainians USA — приложение для украинской общины в США

Мобильное приложение-хаб для украинцев в США: беженцев (U4U, TPS, asylum) и уже
легализованных. Первый рынок — Seattle metro, архитектура рассчитана на
постепенное покрытие всей страны.

## Проблема

Информация о статусах, пособиях, документах и локальной помощи разбросана по
Facebook-группам, Telegram и Viber. Там нет поиска, инфа устаревает, правила
меняются несколько раз в год, и много мошенников. Человеку без английского
почти невозможно понять, что именно относится к его штату и его статусу.

## Решение

Одно приложение, где контент отфильтрован по **городу пользователя** и **его
иммиграционному статусу**, с живым локальным сообществом вокруг.

## Ключевые разделы

| Раздел | Суть |
|---|---|
| **Гайды-чеклисты** | Пошаговые инструкции с прогрессом, разбитые по штатам |
| **Трекер дедлайнов** | Продление статуса, EAD, biometrics — пуши за 90/60/30 дней |
| **Нужды** | Анонимные запросы помощи: деньги, вещи, помощь делом |
| **Чат** | Каналы по темам и по субрегионам метро |
| **Новости** | Иммиграционные, с пометкой «что это значит для тебя» |
| **Организации** | НКО, церкви, проверенные адвокаты, врачи со славянским языком |
| **Работа и жильё** | Объяснительные гайды, как это устроено в США (не доска объявлений — см. [конкурентов](docs/competitors.md)) |
| **События** | Церкви, украинские школы, концерты, выездные консульства |
| **SOS** | Домашнее насилие, кризис, риск депортации — прямые контакты НКО |

## Что осознанно НЕ делаем

- **Не проводим платежи через себя.** Только внешние ссылки (Zelle / PayPal /
  GoFundMe). Иначе — лицензия money transmitter в каждом штате.
- **Не даём юридических консультаций.** Только информация + ссылка на источник
  + дисклеймер.
- **Не автопостим иммиграционные новости.** Только после ручной проверки.
- **Не храним документы и A-number.** Минимум персональных данных.
- **Не строим национальный каталог организаций.** FindHello это уже сделал —
  4000+ ресурсов, 250 городов — и закрылся. Каталог не удерживает
  пользователя. Организации у нас — вспомогательный раздел.
- **Не конкурируем с Ukrainian.us в объявлениях, вакансиях и жилье.** У них
  аудитория и годы контента; там мы не выигрываем.

## Аудитория

Два сегмента с разными потребностями:

- **Недавно приехавшие** — выживание: SSN, страховка, права, школа, работа,
  жильё, пособия. Высокая частота использования, низкая платёжеспособность.
- **Уже легализованные** — сообщество, бизнес, события, помощь другим. Ниже
  частота, выше платёжеспособность, основной источник донатов и волонтёров.

## Монетизация (реалистично)

Беженцы платить не будут. Порядок приоритетов:

1. **Гранты** — ORIA / DSHS (WA), частные фонды, диаспорные организации
2. **Бизнесы** — платные листинги адвокатов, риелторов, автосервисов, врачей
3. **Донаты** от легализованного сегмента на поддержку платформы
4. Job board для работодателей, ищущих русско/украиноязычных

Подписки для пользователей — не рассматриваем.

## Главные риски

1. **Мошенничество в разделе нужд.** Один громкий случай убивает доверие ко
   всей платформе. Верификация обязательна с первого дня.
2. **Приватность.** Аудитория с уязвимым статусом. Политика на запросы данных
   от властей должна быть решена ДО запуска.
3. **Юридический.** Легко быть принятым за юридическую помощь.
4. **Модерация.** Политические конфликты в диаспоре гарантированы.
5. **Пустая комната.** Приложение без людей бесполезно. Первые 500 активных —
   самая тяжёлая часть работы, тяжелее разработки.

## Дорожная карта

**Фаза 0 — валидация (2–4 недели, без кода)**
20–30 интервью в церквях Kent / Renton / Everett и в Ukrainian Community
Center. Вопрос не «нужно ли приложение», а «что было сложнее всего за
последний месяц и где ты искал ответ». Обязательный второй вопрос: «какими
приложениями уже пользуешься и почему перестал». Параллельно — разговор с
координаторами World Relief Seattle / ReWA.

**Фаза 1 — MVP (2–3 месяца, только Puget Sound)**
1. Гайды-чеклисты (federal + WA + Seattle)
2. Трекер дедлайнов
3. Доска нужд (вещи и помощь; деньги — внешней ссылкой)
4. Чат с каналами по субрегионам

**Фаза 2** — проверенные специалисты, события, денежные нужды (через партнёра-
НКО), барахолка. Вакансии и жильё — только объяснительными гайдами.

**Фаза 3** — второй город. Скорее всего Спокан или Ванкувер (WA): тот же штат,
State-слой контента уже готов.

## Разработка

Схема БД лежит в `supabase/migrations/`, стартовые данные — в
`supabase/seed.sql`.

```bash
./supabase/tests/run.sh    # поднимает временную БД, применяет всё, гоняет тесты
```

Смоук-тесты покрывают то, что дороже всего сломать незаметно: трёхслойную
фильтрацию контента, анонимность нужд, изоляцию по RLS и защитные ограничения.
